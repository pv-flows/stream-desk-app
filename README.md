# Stream Deck App (Monorepo)

Repositório monorepo para o sistema de controle Stream Deck, contemplando aplicação desktop e mobile.

## Estrutura do Projeto

- **`.agentes/`**: Instruções e contextos operacionais para agentes de IA.
- **`.github/`**: Workflows de CI/CD e automações do GitHub Actions.
- **`docs/`**: Documentação de arquitetura, changelog e roadmap de tarefas.
  - `docs/ARCHITECTURE.md`
  - `docs/CHANGELOG.md`
  - `docs/TODO.md`
- **`desktop/`**: Aplicação Desktop (Tauri / Rust / Node).
- **`mobile/`**: Aplicação Mobile (React Native / Expo).
- **`global_rules.md`**: Diretrizes gerais de engenharia e boas práticas.
